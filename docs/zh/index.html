独立运行的 Python 编码代理

工作留在日志里。

CadeMini 在你的工作区执行编码任务，然后把每一次任务、模型步骤、工具调用、结果和恢复决策追加到同一份持久会话记录中。继续、回退或审计一次运行，都不需要重新拼凑发生过什么。

核心不变量

历史是被重建的，不是被记住的。

CadeMini 不依赖隐藏的聊天循环来还原自己做过什么。持久事实先写入日志，模型可见上下文再从这份记录中派生。

连续性

恢复分支，而不是恢复一段模糊摘要。

继续最近会话、选择旧会话、浏览完整历史树，或把分支复制成新会话。位置在进程重启后仍然存在。

上下文

压缩，但不假装过去消失了。

压缩会追加一条摘要事实并保留最近尾部。原始记录仍然存在，窗口切换可以用 NOTE.md 作为交接。

/compact/rollover/contexthistory

恢复

撤销影响，保留记录。

文件快照和会话检查点支持撤销、重做、回退和选定文件恢复。恢复会还原受跟踪文件，但不会擦除这一轮的证据。

/undo/redo/rewind/revertcade --undo

执行

工具经过策略，而不是凭感觉运行。

读取、写入、编辑、shell、Python 编排、网页检索、MCP 和委派都是类型化工具调用。模式、规则、授权和 OS 隔离决定什么能执行。

扩展边缘，不扩张核心。

技能按需加载指令。记忆保存持久偏好。MCP 接入外部工具。子代理在独立会话中运行，并保留自己的日志。

接口

安全与控制

有审计轨迹的自主性。

默认的 build 模式追求可用，但不是无限制。每次调用仍要经过模式策略、规则、审批和可用的 OS 沙箱。

审批可以回答一次 ask，但不能覆盖明确的 deny。

各模式的执行策略
场景 plan ask build
查看文件 允许 允许 允许
修改文件 拒绝 询问 允许
普通开发 shell 只读 允许 允许
破坏性 shell 拒绝 询问 询问
MCP 工具 拒绝 询问 询问
可用的 OS 隔离

Linux 使用 bubblewrap，macOS 使用 Seatbelt。Windows 保留应用策略和审批，但不提供 OS 级隔离。

受保护路径始终受保护

显式访问 .env* 和常见凭据路径时，每次都需要审批。授权不能绕过 deny 规则。

默认限制写入范围

workspace-write 只允许写入项目和私有会话临时目录。外部写入需要额外权限。

恢复是显式操作

回退、撤销和恢复会在修改前校验受影响文件。后续编辑冲突会阻止自动恢复。

扩展

能力在边缘，不在第二套运行时里。

技能、记忆、MCP 服务器和子代理都接入同一个循环。它们添加上下文或工具，但不会制造第二个事实来源。

技能

按需加载的指令

只有任务需要时才加载 SKILL.md。引用文件按需读取，脚本仍要走普通 shell 策略。

记忆

跨任务保留的事实

MEMORY.md 保存持久偏好和约定。它进入请求上下文，但不会变成另一条对话消息。

MCP

外部工具，显式命名

连接 stdio 或 Streamable HTTP 服务器。工具以 mcp__server__tool 出现，除非规则允许，否则默认询问。

子代理

独立会话，继承限制

把聚焦任务委派给拥有独立日志的子会话。子会话不能扩大父级权限，也不能递归委派。

核心之所以保持小，是因为每个扩展都从明确的接缝进入。

从这里开始

带一个任务来，带一份记录走。

从仓库安装，认证一次，然后启动终端宿主。CadeMini 把项目会话保存在 .cade/ 下，不依赖早期 Cade 项目。

  1. 01

    安装依赖

    需要 Python 3.12 或更新版本，以及 uv。

    uv sync --locked
  2. 02

    认证 provider

    默认使用 ChatGPT 套餐登录。OpenAI 和 DeepSeek 使用各自的 API key。

    uv run --locked cade login
  3. 03

    打开终端宿主

    直接传入第一个任务，或用 -p 执行一次后退出。

    uv run --locked cade "Review this project."

运行之前

值得先问的问题。

真正重要的是记录、策略和恢复路径，而不是一句关于模型记忆的承诺。

会话状态存在哪里？

会话日志是 .cade/sessions 下的 JSONL 文件。快照和恢复数据位于 .cade/snapshots 和 .cade/recovery。项目配置是 cade.json。

压缩会删除原始历史吗？

不会。压缩会追加摘要事实，并在投影中保留最近尾部。原始记录仍留在会话日志里，可以继续通过 history 工具读取。

每个平台的沙箱一样吗？

不一样。Linux 使用 bubblewrap，macOS 使用 Seatbelt。Windows 跳过 OS 隔离，依赖应用策略、审批和配置的工作区范围。

可以用 API key 代替 ChatGPT 登录吗？

可以。使用 cade login --provider openai 或 cade login --provider deepseek。三条路径都通过 Responses 协议调用模型。

能读取早期 Cade 项目的状态吗？

不能。CadeMini 是独立发行版，拥有自己的凭据、会话和配置格式。请使用干净的 ~/.cade/ 和工作区 .cade/ 目录。
