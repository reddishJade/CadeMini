# Cookbook

Procedures with a concrete outcome and a verification step. Each recipe names
the mode and the evidence to keep.

- [Fix a bug](fix-a-bug.md): reproduce, patch, verify, report.
- [Add a feature](add-a-feature.md): test, implement, verify, review the diff.
- [Review only](review-only.md): investigate in plan mode without mutations.
- [Run a long session](long-session.md): NOTE, compaction, history, and goals.
- [Connect a custom MCP server](custom-mcp.md): configure, allow, call, inspect.

For command details, see [CLI](../cli.md) and [Configuration](../configuration.md).
